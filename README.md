Website ini membantu dalam pelaksanaan praktikum di jurusan Teknik Komputer Undip. Dapat digunanakan sebagai tracking absensi, pencatatan penilaian, belajar materi pada modul yang sudah terintegrasi, dan terdapat fitur penilaian otomatis yang menggunakan teknologi Machine Learning dengan model Transform. Dalam pengembangannya digunakan framework Next JS sebagai Front-end dan Express JS sebagai Backend, serta MySQL sebagai basis data. Sebelum aplikasi ini dideploy, dilakukan pengujian pada model dan aplikasi. Pengujian pada aplikasi menggunakan tools katalon studio, sebagai testing skenario website. Selain itu dilakukan testing menggunakan SonarQube untuk meningkatkan kualitas kode meliputi aspek security, duplikasi code, dll. 




Pada pengerjaannya saya mengerjakan fitur Autentikasi, pendataan absensi dan penilaian. Terdapat 3 role pada aplikasi ini, yaitu admin, praktikan, dan asisten praktikum. Admin memiliki akses untuk manajemen akun dan praktikum. Praktikan dan asisten praktikum dapat mengakses halaman presensi dan penilaian dengan perbedaan pada privillege. Praktikan hanya dapat melihat history presensi dan penilaian sedangkan asisten praktikum dapat melakukan crud. Terdapat fitur komplain yang bertujuan untuk mengajukan komplain ketika terdapat ketidaksesuaian data yang diterima praktikan. Fitur komplain ini bersifat 2 arah, yang artinya asisten praktikum dapat mengonfirmasi komplain yang diterima, untuk kemudian prakitkan dapat melihat status komplain yang diajukan.
